# Security Policy

## Reporting a Vulnerability

CivicNeuro handles South African residents' personal information (POPIA applies) including names, phone numbers, addresses, precise locations, and photos. We take security seriously.

If you discover a security vulnerability, please **do not** open a public GitHub issue. Instead, report it responsibly by emailing **security@civicneuro.co.za** (placeholder — replace with the actual security contact before launch). Include a description of the issue, steps to reproduce, and any proof-of-concept if applicable. We aim to acknowledge all reports within 2 business days and to provide a resolution timeline within 10 business days. We appreciate coordinated disclosure and will credit researchers who report valid vulnerabilities.
